The ABCD Framework

A = Prime (the influencing information)
B = Target (the input being processed)
C = Baseline outcome (without A)
D = Measured outcome (with A)

Three characteristics define priming:
Association — the A–B relationship
Secondariness — A is task-irrelevant
Modulation — A shifts the outcome C → D

Evaluative Conditioning

Learn associations through repeated pairings, then rate your feelings

How This Works:

This experiment has two phases:

Phase 1: Learning

Watch pairs of stimuli appear together.
No response needed - just pay attention.

Phase 2: Rating

Rate how pleasant each stimulus feels.
Use scale 1-7 or keyboard keys.

This demonstrates how associations can change our feelings about neutral stimuli!

Evaluative Conditioning Structure

Unlike single-trial priming, EC involves a learning phase with repeated CS-US pairings, followed by a test phase to measure acquired valence.

Number Comparison Task

Masked numerical priming (Dehaene et al., 1998)

Instructions

  1. A fixation cross (+) will appear - focus on it
  2. Symbols will flash briefly (ignore them)
  3. A number will appear - compare it to 5
  4. Press LEFT ARROW if the number is SMALLER than 5
  5. Press RIGHT ARROW if the number is LARGER than 5
  6. Respond as quickly and accurately as possible
